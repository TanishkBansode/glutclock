UNDER THE HOOD

Sources, pipeline, models, validation rules, and the honest limitations.

Pipeline (twice daily on GitHub Actions)

ingest ──► parquet lake ──► features ──► models ──► verdict + predictions.jsonl
  │            (git)                        │              │
trendforce scrape                    regime rules    digest.md
yahoo/stooq quotes                   logistic proxy  web/index.html
korea customs csv                    momentum p()    pages deploy
press archive                        baselines       scoreboard eval

The git repo is the database: every run commits new rows to data/lake/*.parquet, so history accumulates in version control and any day can be replayed.

Feature engineering notes (things that matter)

  • Merged calendars get forward-filled. US/KRX/JPIX holidays create single-row NaNs across a union calendar; naive rolling windows die on them (this bug shipped and was caught on day one).
  • The memory basket is built from compounded equal-weight returns, never from averaged prices — averaging prices mixes USD/KRW/JPY levels and breaks the moment a constituent lists.
  • No lookahead: features use only data published at or before time t; TrendForce forecast rows are stamped by publication date, never by period covered. Walk-forward evaluation will use purged + embargoed splits (40 trading days) once supervised targets mature.
  • Sanity gate: any spot quote jumping ±35% vs its previous value is flagged sanity_ok=false, quarantined from features, and surfaced as an alert — scrapers fail weird sometimes.
  • Idempotent upserts: re-running a day never duplicates rows; keys are (series,item,date) / (symbol,date) / (url) / (period,window_type).

Why it can (and can't) beat Wall Street

  • Can't win: speed, order-flow, paid feeds (TrendForce Gold+, IDC trackers). Don't try.
  • Can win: slow, public-but-obscure signals — Korean decadal customs prints, capex-event accumulation, spread microstructure (eTT discount, DDR4/DDR5 ratio) — where the edge is reading, not latency, and horizons are weeks-to-quarters.
  • Structural break warning: long-term take-or-pay contracts (Micron's ~$100B book, SanDisk's $93.9B) changed cycle dynamics after 2024. Pre-2024 data is down-weighted in principle; treat old-cycle backtests skeptically.

Honest limitations

  • Physical-price history starts at deployment (TrendForce archives are paywalled) — supervised physical models are cold-starting by construction.
  • Total observable history spans ~5 full memory cycles; statistical power is inherently low. Aim is calibration + early-warning utility, not R².
  • Single-provider dependence on TrendForce's free pages; if their markup changes, adapters break (schema tokens + quarantine alerts limit blast radius).
  • Equity regimes lead physical prices — useful, but never simultaneous.
  • All of it: research tooling. Nothing here is investment advice.
